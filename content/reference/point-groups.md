[[csom|`csom -p/--pg`]] accepts any of these 47 point groups in Schoenflies notation. All of them are analyzed when the flag is omitted.

| Family                      | Point groups                                  |
| --------------------------- | --------------------------------------------- |
| Trivial                     | $E$, $C_{i}$, $C_{s}$                               |
| Cyclic ($C_n$)               | $C_{2}$, $C_{3}$, $C_{4}$, $C_{5}$, $C_{6}$, $C_{7}$, $C_{8}$      |
| Reflection ($C_{nh}$) | $C_{2h}$, $C_{3h}$, $C_{4h}$, $C_{5h}$, $C_{6h}$    |
| Pyramidal ($C_{nv}$)           | $C_{2v}$, $C_{3v}$, $C_{4v}$, $C_{5v}$, $C_{6v}$             |
| Rotation-reflection ($S_n$)  | $S_{4}$, $S_{6}$, $S_{8}$, $S_{10}$                       |
| Dihedral ($D_n$)             | $D_{2}$, $D_{3}$, $D_{4}$, $D_{5}$, $D_{6}$                  |
| Antiprismatic ($D_{nd}$)       | $D_{2d}$, $D_{3d}$, $D_{4d}$, $D_{5d}$                    |
| Prismatic ($D_{nh}$)           | $D_{2h}$, $D_{3h}$, $D_{4h}$, $D_{5h}$, $D_{6h}$, $D_{7h}$, $D_{8h}$ |
| Tetrahedral                 | $T$, $T_{d}$, $T_{h}$ |
| Octahedral                  | $O$, $O_{h}$ |
| Icosahedral                 | $I$, $I_{h}$                                     |

> [!warning] Point group names
> Names are typed in plain text and are case-sensitive: write `Oh` for $O_h$, not `oh`, `OH` or `O_h`.
